# Nabta

Nabta is a sustainable marketplace and community platform designed to encourage eco-friendly habits through item swapping, upcycling, and circular economy practices. The platform enables users to trade clothes, share upcycling ideas, and participate in a green community to reduce waste and environmental impact.

This project was developed by 2nd-year students at Helwan University.

## Features
- **Marketplace:** Browse and swap items with other users.
- **Upcycling:** Discover and share creative ways to repurpose old items.
- **Community:** Join groups and discussions focused on sustainability.
- **Profile & Closet:** Manage your items and track your environmental impact (CO2 and water savings).
- **Admin & Moderator Dashboard:** Tools for managing reports and community health.

## Technology Stack
- **Backend:** PHP (MVC Architecture)
- **Database:** MySQL
- **Frontend:** HTML, CSS (Custom styles), JavaScript
- **Security:** CSRF protection, secure session management, and data encryption.

## Project Structure
- `app/`: Core application logic (Controllers, Models, Config, Views).
- `public/`: Entry point and routing.
- `assets/`: Static files like CSS and images.
- `database/`: Database scripts and migrations.
